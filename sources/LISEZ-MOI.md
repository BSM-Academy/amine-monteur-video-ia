# Tes vidéos à traduire

Dépose ici la pub à traduire (fichier .mp4, 25 Mo maximum par l'interface GitHub) :
**Add file → Upload files**, puis **Commit changes**.

Ensuite, sur claude.ai/code, écris par exemple :
« Traduis la vidéo `sources/ma-pub.mp4` en français. Ma marque : …, mon produit : …, mon site : … »
