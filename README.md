# AdCloner

Traduis et adapte tes pubs vidéo dans une autre langue (voix clonée, sous-titres, textes à l'écran), directement dans Claude, sans rien installer sur ton ordinateur.

- **Première fois ?** Suis le [guide d'installation](https://contactsyriusmedia-create.github.io/adcloner-guide/).
- **Traduire une pub :** dépose la vidéo dans le dossier `sources` de ton dépôt `mes-videos-adcloner`, lance AdCloner avec le bouton du tuto, puis écris : « Traduis la vidéo `sources/ma-pub.mp4` en français ».
- **Récupérer tes vidéos :** Claude te donne un lien à la fin. Elles sont aussi dans le dossier `livraisons` de ton dépôt `mes-videos-adcloner`.
- **Mises à jour :** rien à faire, tu utilises toujours la dernière version d'AdCloner.
