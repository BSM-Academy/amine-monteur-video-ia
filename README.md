# AdCloner

Traduis et adapte tes pubs vidéo dans une autre langue (voix clonée, sous-titres, textes à l'écran), directement dans Claude, sans rien installer sur ton ordinateur.

- **Première fois ?** Suis le [guide d'installation](https://contactsyriusmedia-create.github.io/adcloner-guide/).
- **Traduire une pub :** dépose la vidéo dans `sources/`, puis sur [claude.ai/code](https://claude.ai/code), choisis ton environnement **AdCloner** et écris : « Traduis la vidéo `sources/ma-pub.mp4` en français ».
- **Récupérer tes vidéos :** Claude te donne un lien à la fin. Tes vidéos sont aussi dans la branche `livraisons` de ce dépôt.
- **Mettre à jour AdCloner :** sur la page GitHub de ton dépôt, clique sur **Sync fork**, puis **Update branch**.
